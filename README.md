# Cubby

A macOS menu bar app for capturing context throughout the day.

Cubby keeps the things you copy, screenshot, and jot down in a chronological feed, always a click away in the menu bar.

## Download

[Download the latest release](https://github.com/GrahamBunt/cubby-releases/releases/latest)

Requires **macOS 14 Sonoma or later**. One installer supports **Apple Silicon and Intel Macs**.

## Install

1. Download the `.dmg` attached to the latest release.
2. Open it and drag **Cubby** into **Applications**.
3. Open **Cubby** from Applications. Its icon appears in the menu bar.

If you already have Cubby installed, quit it before replacing it in Applications.

Cubby is signed with a Developer ID certificate and notarized by Apple.

## About this repository

This repository hosts Cubby's public downloads and release notes. The application source code is maintained separately in a private repository.
